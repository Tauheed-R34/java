Practical 4: Right-Angled Triangle Star Pattern Using Loops
Aim: To write a Java program to print a right-angled triangle star pattern using for, while, and do-while loops.
Theory: Loops are used to execute a block of statements repeatedly. The for loop is generally used when the number 
of iterations is known, the while loop checks the condition before execution, and the do-while loop executes at 
least once. Nested loops are used to print the triangle pattern.
